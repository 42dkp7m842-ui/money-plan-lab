## 分析タブ（v1.7）

GitHub Pages上で個人情報を送信せず、端末内のZaim CSVと既存設定から次の分析を表示します。

- **現在地**：目標の現在額・目標額・残額・期限までに必要な月額。実残高は「設定」または目標に入力した値を使用します。
- **月次グラフ**：収入・生活支出（現金引出とチャージを除く目安）と参考収支差額。開始日が月の途中なら「途中から」と表示します。
- **カテゴリ分析**：前月比、手入力したカテゴリ予算との差、予算超過表示。予算設定は端末内データとしてバックアップ可能。
- **固定費と高額支出**：固定費は別台帳で管理し、支出総額へ二重加算しません。高額明細（1件15,000円以上）は生活支出の内訳として区別します。
- **貯金シミュレーション**：月次積立を3万円・5万円・7.5万円・12.5万円などで試算。3か月、6か月、12か月後の参考額と目標達成見込みを表示します。
- **リスクと改善提案**：給与日・カード引落日の資金不足、カテゴリ超過、「その他・未分類」の多さ、集計期間不足などをルールベースで警告します。
- **分析レポートのコピー**：Zaimの集計結果をテキストでコピーします（個人データは共有・自動送信しません）。

**注意**：`収入−生活支出`は実際の貯金額ではありません。クレジットカードの計上日と銀行引落日が異なること、現金払い・借入・口座振替などの扱いが異なるためです。貯金進捗は実際の銀行残高や登録済みの貯金額と照合してください。実際の残高をZaim CSVから自動同期する機能ではありません。

# Money Plan Lab

iPhone向けの個人用・資金繰り管理Webアプリです。ZaimのCSV明細、カード請求、サブスク、銀行口座残高、借入返済、貯金目標をまとめて表示します。

## iPhoneで公開する

1. GitHubでこのリポジトリの **Settings → Pages** を開く。
2. **Build and deployment / Source: Deploy from a branch** を選ぶ。
3. **Branch: main / Folder: /(root)** を選び、**Save**。
4. 公開された `https://42dkp7m842-ui.github.io/money-plan-lab/` をSafariで開く（反映されるまで多少時間がかかる場合があります）。
5. **設定 → バックアップを読み込む** から、チャットで受け取った個人用JSONファイルを**ブラウザ内だけで**取り込む。
6. Safariの共有メニュー → **ホーム画面に追加**。ホーム画面版ではデータ保存領域が別になる場合があるため、必要なら同じJSONを再度読み込みます。

## ChatGPTから将来の資金計画・目標を取り込む

1. アプリの **AI計画** タブを開き、**ChatGPT用プロンプトをコピー** を押します。
2. ChatGPTに貼り付け、追加したい計画（例：「来月は月5万円生活、年末までに貯金100万円」）を相談してJSONを出してもらいます。
3. ChatGPTから返された **JSONテキストを貼り付け**、または **.jsonファイルを選択** します。
4. **取り込み内容を確認** を押し、目標・対象月・設定の変更点を確認します。
5. **確認して反映する** を押すと、目標と月別計画が追加・更新されます。
6. ホームの「ChatGPTからの計画」、AI計画の一覧、資金繰り予測で反映を確認してください。

### 入力形式

```json
{
  "format": "money-plan-lab-ai-v1",
  "goals": [
    {
      "id": "example-goal",
      "title": "旅行積立（例）",
      "type": "savings",
      "targetAmount": 120000,
      "deadline": "2028-12-31"
    }
  ],
  "monthlyPlans": [
    {
      "month": "2028-06",
      "savingTarget": 10000,
      "livingBudget": 45000
    }
  ],
  "settings": {}
}
```

**目標（goals）**：`id`、`title`、`type`、`targetAmount`、`deadline`、`currentAmount`、`memo` に対応。目標の `type` は `savings` / `debt` / `spending` / `custom`。

**月別計画（monthlyPlans）**：`month` は必須で、`income`（通常収入）、`savingTarget`（貯金目標）、`livingBudget`（生活費の総予算）、`cardBudget`（新規カード利用予算）、`debtPayment`（借入返済）、`cashLiving`（カード以外の予定支出）、`extraIncome`（臨時収入）、`extraExpense`（臨時支出）、`memo` に対応。

**基本設定（settings）**：`salary`、`salaryDay`、`scholarship`、`scholarshipDay`、`debtPay`、`debtDay`、`cashLiving`、`livingBudget`、`saving`、`startMonth` だけ更新できます。

同じ `id` の目標・同じ `month` の月別計画は更新されます。登録済みの確定カード請求、Zaimの取引、口座残高、借入残高は変更しません。AI計画の再取込は「全データ復元」とは違い、計画だけ差分反映します。貯金目標とカード予算は予算枠のため **口座残高から差し引きません**。また、生活費予算とカード外支出は区別してください（生活費の総予算を丸ごとカード引落に加えない）。月ごとの `cashLiving`、`debtPayment`、`income`、`extraIncome`、`extraExpense` は試算に反映します。

## 取り込んだZaim明細を削除する（v1.6）

**Zaim取込** タブの「取り込んだ家計簿」から、次の4通りで削除できます。

1. **1件だけ削除**：明細の右側にある「削除」を押す（表示は直近30件まで）。
2. **月ごと削除**：対象月を選択して「表示中の月をすべて削除」を押す。
3. **取込CSVごと削除**：「取込ファイル別に削除」から該当ファイルの「この取込を削除」を押す。
4. **全件削除**：「全Zaim明細を削除」を押す。

削除前に確認画面を出します。直後は「直前の削除を元に戻す」で復元できますが、画面を再読み込みすると取り消しはできません。**削除前に必ず「設定 → バックアップを書き出す」を検討してください。**

v1.5以前のZaim明細にはファイル識別情報がないため、「以前の取込（ファイル不明）」としてまとめて表示します。ファイル単位の識別はv1.6以降に取り込んだCSVに対応します。

この削除で変わるのは、Money Plan Labに保存したZaim明細だけです。**Zaim本体・銀行・カード・サブスク・口座残高・AI計画には影響しません。** 削除した明細も、その後同じCSVを再度取り込めば復活します。

## CSVの収入・支出が大きすぎるとき

v1.5 では、実際のZaim CSVに含まれる「集計に含めない」を正しく除外し、負の支出（返品・割引）も符号付きで計上できるようにしました。現金引出・電子マネーチャージ・カード引落は「Zaim設定上の支出」とは別に「生活支出（目安）」から控除して表示します。残高調整の行は収入・支出へ入れません。

**修正前のZaim取込明細がある場合は「追加」ではなく「入れ替え」を選んでください。**

v1.3 では、Zaim CSVの「集計の設定」列に対応しました。「常に含めない」と「年ごとのみ含める」は月間集計から除外します。「月ごと・年ごとに含める」は月間集計に含めます。銀行・クレカ・電子マネー間の振替は収入・支出に含めません。

- まず **設定 → バックアップを書き出す** でJSONを保存します。
- **Zaim取込** で再びCSVを選ぶと、月別の収入・支出・除外額・振替がプレビューされます。
- 確認後に **このCSVでZaim明細を入れ替える** を押すと、旧Zaim取込明細だけを置換します。カード請求・口座残高・固定費・AI計画は維持されます。
- CSVに「集計の設定」列がない場合、除外されたカード決済やチャージを再現できません。列の値が不明な場合も警告を表示します。実際のZaim集計との一致は保証されません。
- 同じCSVを連続して追加する場合は重複を抑制しますが、名前やメモが変わった明細は別取引扱いになる可能性があります。

## ZaimのCSVから更新する

1. Zaim Web版でCSVデータをダウンロードする。
2. このアプリの **Zaim取込** → **CSVファイルを選択**。
3. 同じ明細を再取込した場合は、日付・金額・内容などで重複を抑制します（完璧な重複除去は保証しません）。
4. **カード** タブの請求予定と **設定** タブの口座残高は必要に応じて更新してください。CSVだけではカード支払予定や口座残高を自動確定できません。

## 大切な注意

- **ZaimのCSV・個人用JSON・通帳・カード番号・パスワード・APIキーなどをGitHubにアップロードしないでください。** この公開リポジトリには汎用のアプリ本体のみ置いてあります。
- 取り込んだデータはブラウザの`localStorage`に保存します。暗号化やクラウド同期はなく、ブラウザのデータ削除で消えるため、設定画面から定期的にJSONバックアップしてください。バックアップ自体も暗号化されません。
- 同じ `github.io` ドメイン上の別アプリも同一オリジンの保存データにアクセスできる場合があります。個人情報を扱う場合は慎重に利用し、必要なら独自ドメイン／認証付きの保管先を検討してください。
- カード請求に既に含まれるサブスクやジム代は、資金繰りで二重計上しません。Zaim CSVの家計簿分析はキャッシュフローと別管理です。
- 未来のカード利用・金利・手数料などは自動予測されません。資金繰りは目安であり、実際の口座引落日・請求額・残高を優先してください。
